# soredemo Brand Kit v1

This package contains the selected custom `そ` logomark and production-ready
brand assets.

## Recommended assets

- App / GitHub / npm avatar: `svg/soredemo-logomark-white.svg`
- Dark website header: `svg/soredemo-horizontal-lockup-white.svg`
- Light website header: `svg/soredemo-horizontal-lockup-black.svg`
- Japanese identity use: `svg/soredemo-japanese-wordmark-*.svg`
- Favicon: `favicon/favicon.svg` or `favicon/favicon.ico`
- One-color printing: white or black SVG variants

## Notes

- SVG typography has been converted to paths, so no font installation is required.
- PNG files use transparent backgrounds except the palette and dark favicon.
- The logomark is monochrome-first. Accent blue is optional, not required.
- Keep clear space around the mark equal to roughly one quarter of its height.
- Avoid adding browser frames, cursors, recording dots, gradients, or extra effects
  to the primary logomark.
